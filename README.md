# مخبز حارتنا 🥐

لعبة عائلية خفيفة للجوال والتابلت: اضغط الفرن تطلع عجينة، اسحب الحبتين المتشابهة فوق بعض عشان تكبر، وقدّم للزبون اللي يبيها. اجمع 250 ريال في 90 ثانية.

**السلسلة:** عجينة ← لقيمات ← كليجا ← معمول ← كيكة التمر 👑

- ملف واحد `index.html` بدون أي مكتبات أو مفاتيح.
- عربي بالكامل ومن اليمين لليسار.
- تشتغل باللمس على الجوال (بالطول) والتابلت (بالطول وبالعرض).
- أفضل نتيجة تنحفظ على جهازك بس.
